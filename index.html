Privacy Policy — AtlantisRP Discord Bot

The AtlantisRP Discord Bot is used exclusively for administration, moderation, access control and logging related to the AtlantisRP FiveM roleplay server.

Data we access

  • Discord User ID
  • Discord username and display name
  • Server membership status
  • Discord roles assigned within the AtlantisRP server

How we use this data

This information is used only for membership verification, permission checks, moderation, administration and generating administrative logs sent to private AtlantisRP Discord channels.

Data storage

The bot does not create an external database of Discord member data unless explicitly required by an AtlantisRP service.

Discord information may appear in administrative logs stored in private AtlantisRP Discord channels.

We do not sell, rent or share Discord user data with third parties.

Data retention

Administrative logs may remain available in private AtlantisRP Discord channels according to the server's moderation and logging practices.

Data sharing

Discord data is used only within the AtlantisRP administration environment. It is not used for advertising, marketing or user profiling.

Security

Access to administrative logs and bot functionality is restricted to authorized AtlantisRP staff and Discord roles.

User requests

Users may contact AtlantisRP administration regarding questions about the use of their Discord information or stored administrative records.

Changes

This Privacy Policy may be updated if the bot's functionality or data handling practices change.

Polityka prywatności — AtlantisRP Discord Bot

Ostatnia aktualizacja: 13 października 2026

Bot Discord AtlantisRP jest używany wyłącznie do administracji, moderacji, kontroli dostępu oraz logowania zdarzeń związanych z serwerem FiveM AtlantisRP.

Dane, do których bot uzyskuje dostęp

  • Discord User ID
  • nazwa użytkownika i nazwa wyświetlana
  • status członkostwa na serwerze
  • role przypisane na serwerze AtlantisRP

Sposób wykorzystania danych

Dane są wykorzystywane wyłącznie do weryfikacji członkostwa, sprawdzania ról i uprawnień, działań administracyjnych i moderacyjnych oraz tworzenia logów wysyłanych na prywatne kanały Discord AtlantisRP.

Przechowywanie danych

Bot nie tworzy zewnętrznej bazy danych członków Discord, chyba że jest to wyraźnie wymagane przez konkretną usługę AtlantisRP.

Informacje Discord mogą pojawiać się w logach administracyjnych przechowywanych na prywatnych kanałach Discord AtlantisRP.

Dane użytkowników nie są sprzedawane, wynajmowane ani przekazywane podmiotom trzecim.

Okres przechowywania

Logi administracyjne mogą pozostawać dostępne na prywatnych kanałach Discord zgodnie z zasadami moderacji i logowania AtlantisRP.

Udostępnianie danych

Dane Discord są wykorzystywane wyłącznie w środowisku administracyjnym AtlantisRP i nie są używane do reklam, marketingu ani profilowania użytkowników.

Bezpieczeństwo

Dostęp do logów administracyjnych i funkcji bota mają wyłącznie upoważnieni członkowie administracji AtlantisRP.

Kontakt i żądania użytkownika

Użytkownicy mogą skontaktować się z administracją AtlantisRP w sprawach związanych z wykorzystaniem ich danych Discord lub zapisanymi logami administracyjnymi.

Zmiany polityki

Polityka prywatności może zostać zaktualizowana, jeśli zmieni się funkcjonalność bota lub sposób przetwarzania danych.
